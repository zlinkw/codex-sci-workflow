# 数据与显示契约

库根目录 `阅读偏好.md` 保存本库约定。`批次/` 保存选择映射，`论文/` 是每篇论文唯一笔记，`主题/` 保存问题级综合，`对照/` 放派生 Canvas，`附件/` 放 PDF 和图片，`引用导出/` 只放可重建的书目输出，`导出/` 放用户需要的 PDF 阅读包。

## 论文身份与字段

优先使用 DOI，再使用 arXiv ID 或其他可靠标识。论文身份 `paper_id` 与可用于文件名的 `id`/引用键不同，保留二者映射。不要把含斜杠、冒号的原始 DOI 直接用作 Windows 文件名。已有引用键不因补上期刊版而自动改变。

书目遵循 BibLib 的 CSL-JSON 字段：`id`、`type`、`title`、`author`、`container-title`、`issued`、`DOI`、`URL`。不凭记忆补作者、页码或 DOI。用于卡片的 `venue`、`year` 是从核实书目提取的显示字段，不是独立书目真源。

阅读字段：`note_kind: paper`、`paper_id`、`reading_stage`（速览/详细）、`batch_id`、`quick_index`、`detail_index`、`cover`、`attachment`、`topics`、`expand_requested`、`retain_requested`、`source_version`、`reading_scope`。`paper/retained` 标签是正式收藏状态。`reading_stage` 不是收藏授权。

准入字段见批次指南。`venue_eligible` 为 true/false，尚未核实时留空。不能用“已收藏”倒推期刊或会议合格。

## 正文与保护区

依次保留速览、详细阅读、与其他论文的关系、用户笔记。批次页通过标题嵌入正文，而非复制正文。AI 更新只覆盖自己的相关段落。用户笔记、手写批注和用户纠正过的内容原样保留，来源变化有实质影响时说明差异。

`cover` 必须指向本论文完整模型框架图，与正文框架图复用同一图片文件。没有框架图就留空并说明，不拿实验图、期刊标志或 AI 图替代。Bases 卡片 `imageFit: contain`，正文完整显示原图。

## 图片与公式接入

用户自行适配本地提图工具。本技能接收论文身份、PDF 版本、本地图片路径、图表公式类型、图号、页码、图注以及可选 bbox/LaTeX。没有 bbox 或 LaTeX 不构成读取障碍。

只引用明确属于该论文和版本的原图。保存到本库附件区后使用库内链接，复用已存在附件，不依赖工具的可重建临时图库路径。不得直接改其他插件数据库，也不为对接复制整套图库。原生矢量保留 SVG，位图不以放大或描摹冒充恢复出的原始细节。OCR LaTeX 与公式原图并列核对，不静默修正数学意义。

## 书目与导出

本库 BibLib 的识别标签是 `paper/retained`。Codex 建立候选时只加 `paper`，最终确认才加收藏标签，所以候选不会进入正常书目导出。用户在 BibLib 对话框主动“创建文献笔记”是直接手动添加收藏的入口，不是自动速览入口。对此在库内说明，不把检索结果批量走该入口。

只为选中收藏补齐正式书目。生成标准 BibTeX 供 LaTeX 使用，不直接改真实手稿的 `.bib`。写作项目通过额外项目标签和 BibLib export profile 限定。用户尚未建立项目时不虚构项目目录或添加示例文献。

正式导出时核实实际标签范围和元数据，空库允许生成空书目，不添加虚构条目用于演示。BibLib 标准书目与项目导出都是笔记的派生产物，不另维护一份可独立编辑的主库。
