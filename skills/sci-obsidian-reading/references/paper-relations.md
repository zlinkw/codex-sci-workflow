# 有依据的论文关系

只按本轮论文和已选相关论文检索，不建立全库语义索引。先读取相关原文和用户已有解释，主题图不以连线数量为目标。

| 关系 | 最低依据 |
|---|---|
| 引用 | 已核实引用记录，方向为引用者指向被引者 |
| 同一问题、不同解法 | 两篇原文的具体问题与解法，不能只有关键词重合 |
| 延伸或重构 | 两篇原文中改变的假设、机制或问题定义 |
| 支持或存在差异 | 可比较的条件、主张与已检查证据 |
| 可能互补/可能迁移 | 读者设想、前提和未验证状态，不当作实验结论 |

在论文关系表保留目标论文链接、关系方向和类型、短理由、两侧原文位置、依据是作者陈述/阅读推断/未验证设想，以及所读版本。只看摘要的论文不能被标成已完成方法比较。预印本和期刊版先标为同一工作的版本关系。

正文关系表是权威内容。主题笔记综合问题、挑战、思路、论文与证据边界，不复制整篇阅读笔记。用户修订后的关系优先，不在刷新图时复原旧推断。

Canvas 引用真实笔记或附件，箭头标注关系，必要时链接到正文的依据。自由文本卡片不是关系真源，不把没有内容依据的空间邻近当成事实。默认小范围对照，围绕当前感兴趣的问题选择论文，不为了固定数量加无关节点。

原生图谱展示笔记链接，不自动理解或显示全部科学关系类型。默认看局部图谱，排除候选噪声与附件。图谱没有语义边过滤能力时不承诺它有。需要带类型的视觉对照时用 Canvas。
