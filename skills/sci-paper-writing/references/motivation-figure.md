## Motivation figure

First decide the role: an introduction motivation figure explains the problem, relevant limitations and the proposed response. It is distinct from a detailed Method architecture figure. A useful source-inspired layout is **原始问题 + 关键局限面板 + 本文方案**. The actual problem and challenge set determine the panel count and organization; a reference figure's layout is not a required structure for another study.

Plan each panel's scientific message before drawing:

- The original-problem panel shows the domain gap, constraint or failure condition needed by the argument.
- Limitation panels distinguish the actual mechanisms/consequences raised in the challenge paragraphs, instead of drawing the same generic poor result repeatedly.
- The proposed-method panel shows the targeted action and intended change. Clearly identify conceptual distributions or predictions as schematic; do not imply an actual t-SNE, metric or verified outcome without real evidence.
- Choose a visual encoding that exposes the specific variable, relationship or change named in the current claim. Keep compared conditions and relevant units identifiable, and distinguish conceptual explanation from measured evidence. Do not import a reference project's scientific problem or visual analogy solely because its layout is convenient.
