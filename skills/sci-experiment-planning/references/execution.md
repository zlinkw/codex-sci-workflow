# 通用实验执行与文件传输

本指南约束执行结果与证据，不绑定插件。实际运行、恢复或传输时读取，纯论文写作不加载。用户当前授权和项目实际契约优先，不把历史工具选择当成永久要求。

## 运行前

- 核实项目根、运行主机与环境、配置、数据划分、种子、命令、资源和独立输出目录。复用现有计划位置与格式，新计划通常放在 `experiments/plans/`。不为更换执行工具强制迁移已有项目。
- 根据当前任务选择已安装且适用的脚本、CLI、调度器、SSH/tmux 或 API。SimpleExperiment/SimpleSFTP 是可选实现，仅选用它们时加载对应技能及接口契约。不得为满足本指南自动安装插件或建立服务。
- 做适用的配置、输入、环境和输出冲突检查。有实际 dry-run 能力时使用，无此能力时做等价的无副作用预检并说明边界，不声称做过 dry run。短训练或推理仍是实验执行，不能伪装成只读检查。
- 写计划不等于获准运行。复用用户已批准的任务、资源和目标范围，重大新增成本、目标变更及危险操作按实际授权确认。新请求明确批准执行时，不逐步重复索取同一许可。

## 运行与恢复

- 为每次尝试记录可追溯身份、配置、代码版本、数据划分、种子、环境、开始与结束状态、日志和结果。复用项目或调度器的记录，不新增平行台账。
- 可以直接运行项目的正式训练/测试入口，但须使用已核实配置与命令，保留真实退出码及完整失败信息。任务已提交不等于运行成功，成功退出不等于指标有效。
- 长任务使用项目已有的调度或会话机制。恢复前检查既有进程、任务与输出，不重复提交状态未知的工作，不中断用户正在运行的任务。
- 独立任务按资源与输出隔离条件并行，依赖任务按已完成输入顺序执行。不得为了占满 GPU 改变科学协议或增加无关种子。
- 有效运行的纳入、失败与重试、统计单位和比较边界统一遵循 [结果有效性与统计](../../sci-results-analysis/references/statistical-validity.md)。

## 文件与服务器

- 从当前项目和连接配置核实主机、端口、账号、本地源、远端根及具体目标。只读取所需配置，不输出密钥、token 或密码。不继承其他项目的路径。
- 可以使用 SSH、SFTP、scp、rsync、现有同步工具或 API。按本次权限和文件范围选择，不要求经过指定插件。使用 API 时按该接口的实际发现/帮助文档取得参数，并遵守其确认机制。
- 上传仅包含必要且稳定的文件。检查忽略规则、同名覆盖及本地/远端改动，不用同步覆盖未知的新版本，不默认上传数据集、权重、环境或凭据。
- 传输后确认目标与结果，必要时比较相关文件版本或摘要。读取、连接失败、部分传输及未知完成状态必须可见，不静默换目标或声称同步成功。
- 选择工具不授予删除权限。任何完整文件/目录删除或同步删除仍须按当前删除安全规则核实精确目标、授权、根与直接父目录，不自动启用删除选项。

已有项目中仅由旧全局默认带入的“必须使用插件”要求不再适用。真实的访问控制、机构规定或明确项目限制仍需遵守，不能以通用化为由绕过。
